Deployment

The launchpad with all the applications of the workspace, or one application alone: Docker, docker compose, SAP BTP Cloud Foundry (cf push), any Node.js server.

Get started in two minutes

  1. Install the extension (it contains everything: rapt, OpenUI5, an embedded database).
  2. RAP: New complete business object… creates a managed BO with data, and adds it to the launchpad of the workspace.
  3. RAP: Start rapt dev asks for the floorplan (List Report, Worklist…) and opens the application; it is rebuilt on each save.
  4. RAP: New RAP object… adds views, BDEFs, services… as in ADT. rapt is also on the PATH of the terminals, and the agent mode of VS Code finds rapt agent.

Or on the command line

npm install -g open-rap-runtime

rapt new my-project Travel --prefix ZRT
rapt dev my-project
# http://localhost:8080/

rapt check my-project       # diagnostics
rapt build my-project --out dist
rapt abapgit my-project     # XML for SAP
rapt agent .                # MCP server for coding agents

Frequently asked questions

Do I need an SAP license?

No. Open RAP Runtime uses no proprietary SAP library: OpenUI5 (Apache 2.0), abaplint (MIT), PostgreSQL. The sources stay yours and are imported into an SAP system with abapGit.

Will my BO behave as on SAP?

That is the rule of the project: in standard mode, a source behaves as on SAP, and what would not activate there is refused with a diagnostic. The known gaps are documented.

And in production?

The generated application is an ordinary Node.js application: Docker, Kubernetes, SAP BTP Cloud Foundry, with PostgreSQL and the OIDC authentication of your identity provider (Keycloak, SAP Cloud Identity Services, Entra ID…). See the deployment guide.

Can an AI agent write the BO?

Yes. In VS Code, the agent mode finds the MCP server of rapt (rapt agent): it checks the project, creates objects and searches this documentation; rapt is also on the PATH of the terminals. Elsewhere: npm install -g open-rap-runtime, then for example claude mcp add rapt -- rapt agent .. See the guide.

Where is the documentation?

On this website (documentation), and in the launchpad of rapt dev (Documentation tile).

How do I report a bug or ask for a feature?

With the feedback form: it opens a pre-filled issue in the public feedback repository. In VS Code: RAP: Report a bug or request a feature… fills in the version and the environment.
