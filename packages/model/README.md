# @rap-transpiler/model

Les types de la représentation intermédiaire (`model.json`) de [rap-transpiler](https://github.com/ClementRingot/RAP-Transpiler),
partagés par le compilateur (`@rap-transpiler/compiler`) et le runtime (`@rap-transpiler/runtime`),
et les dérivations communes (OData, value helps, MCP).

Pour la ligne de commande `rapt` : `npm install -g rap-transpiler`.
