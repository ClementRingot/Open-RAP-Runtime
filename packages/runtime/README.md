# @rap-transpiler/runtime

The generic runtime of the applications produced by
[rap-transpiler](https://clementringot.github.io/RAP-Transpiler/): Fastify server, OData V4
(`$batch`, draft, ETags), RAP managed runtime, execution of the transpiled behavior pool, OIDC
authentication, launchpad and MCP server.

An application generated by `rapt build` bundles it in `vendor/`; `rapt dev` uses it directly.
Installed with the command line:

```sh
npm install -g rap-transpiler
```
